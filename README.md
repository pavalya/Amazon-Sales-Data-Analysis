# Amazon India Sales Analysis: Data Cleaning and EDA

Data cleaning and exploratory analysis of 47,000 Amazon India sales records using Python.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn (Google Colab)

## What I did
- Removed duplicates and junk columns
- Standardised dates, status and city names
- Handled missing values, invalid quantities and outliers
- EDA: sales trends, category and city performance, cancellation rate

## Files
- Amazon_sales_analysis.ipynb: full notebook
- cleaned_amazon_sales.csv: cleaned dataset
- messy_amazon_sales_47k.csv: raw dataset

Note: the dataset is a synthetic practice dataset modelled on the Amazon India sales report.
